# Fanwaave

Fanwaave builds reliable communication and fan-engagement infrastructure.

## Canonical repositories

- [push-notification-server.rs](https://github.com/fanwaave/push-notification-server.rs) — Rust notification delivery for FCM, APNs, Expo, Web Push, SendGrid, and Twilio lanes.
- [.github](https://github.com/fanwaave/.github) — organization profile, governance, security, repository boundaries, and shared project context.
